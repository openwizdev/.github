# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting on the affected repository: `https://github.com/openwizdev/<repo>/security/advisories/new`. It is enabled on every public openwizdev repository. Never report a vulnerability in a public issue.

We'll acknowledge your report within 3 business days and work with you to coordinate a fix and disclosure.

## Scope and supported versions

This policy covers every public [openwizdev](https://github.com/openwizdev) repository and [openwiz.dev](https://openwiz.dev). A repository with its own `SECURITY.md` follows that file instead.

We support the latest release and the `main` branch.

The site's [security.txt](https://openwiz.dev/.well-known/security.txt) points to the OpenWiz advisory page; for any other repository, use that repository's advisory page.
