# openwizdev/.github

The [openwizdev](https://github.com/openwizdev) org profile. The page itself is [`profile/README.md`](profile/README.md).

`profile/art/` holds the pictures: the banner and the repo map, and the painted Wiz (`wiz.png`) and lockup (`lockup-light.png`, `lockup-dark.png`) that every repo README shows at its top.

`SECURITY.md` is the default security policy GitHub shows for any openwizdev repository without its own.
